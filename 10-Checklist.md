# Daily Schedule (3 Hours)

**Hour 1**

* Learn theory

**Hour 2**

* Lab practice

**Hour 3**

* Take notes and repeat commands from memory

The most important thing is that every month includes hands-on practice. Reading about Nmap, Wireshark, Burp Suite, or Active Directory is useful, but actually using them is what turns knowledge into employable skill.
